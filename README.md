# 🎨 Quadrados Coloridos

Projeto desenvolvido com **HTML5 e CSS3** para praticar os fundamentos do desenvolvimento front-end.

## 📌 Sobre o projeto

A página apresenta cinco camadas coloridas organizadas em um contêiner. O projeto foi criado para praticar a estruturação de elementos HTML e a estilização com CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Box Model

## 📂 Estrutura do projeto

```text
quadrados-coloridos/
├── index.html
├── README.md
└── styles/
    └── styles.css
```

## 📚 Conceitos praticados

- Estrutura básica do HTML.
- Seletores e propriedades CSS.
- Cores, margens e espaçamentos.
- Largura, altura, padding e bordas.
- Organização de elementos com Flexbox.
- Estruturação de contêineres e camadas.

## 🎯 Objetivo

Praticar os fundamentos de HTML e CSS por meio de projetos simples, desenvolvendo gradualmente minhas habilidades em desenvolvimento front-end.
